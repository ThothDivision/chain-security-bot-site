# Chain Security Bot — public preview site

Static landing page for **Chain Security Bot** (working name), an early-preview contract scanner and chain-invariant monitor for Cosmos (CosmWasm, IBC) and EVM chains.

- Live preview: https://thothdivision.github.io/chain-security-bot-site/
- This repo only holds a copy of the main repo's `site/` folder, which is the source of truth. The main repo is private during the preview.
- Fonts: Inter Tight and JetBrains Mono, both SIL Open Font License 1.1 (see `fonts/`).
- Deploys to GitHub Pages with `.github/workflows/pages.yml`.
